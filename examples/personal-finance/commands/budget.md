description: Build a simple monthly budget from your own numbers, using a clear method — income first, then a plan that adds up.
---
Help the user build (or refine) a simple monthly budget in `budget.md`, using a
clear method. You teach the method and do the arithmetic; the numbers and the
decisions are theirs. This is educational budgeting, not financial advice — if a
question needs a professional (debt, taxes, investing), say so.

Work in this order:

1. **Income.** Monthly take-home (after tax). If it varies, use a conservative
   average and note it.
2. **Fixed costs.** Rent/mortgage, utilities, subscriptions, transport, insurance
   — the bills that come whether or not they think about them.
3. **A method for the rest.** Offer a simple frame and let them choose:
   **50/30/20** (needs / wants / savings+debt — see the skill) as a starting
   split, or **envelopes** (a capped amount per category — see the skill).
   Explain the trade-off; do not impose one.
4. **An emergency-fund line** near the top of savings, unless they already have a
   starter fund. Explain why most methods put it first (the `emergency-fund`
   skill).
5. **Make it balance.** Check that everything sums to income; if the plan spends
   more than it earns, show the gap and help find the smallest realistic change.

Write it as a plain table in `budget.md`. Keep it simple enough to actually keep.
Offer to run the read-only `budget-reviewer` to check the arithmetic.
