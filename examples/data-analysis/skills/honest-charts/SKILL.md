# Honest charts

A chart is an argument. An honest one lets the reader check it; a dishonest one
hides the check. The rules are few and non-negotiable:

- **Label every axis, with units.** An unlabeled axis is not a chart, it is a
  decoration.
- **Do not truncate a y-axis to exaggerate a change** — start bars at zero. If a
  non-zero baseline is genuinely needed, say so in the caption.
- **Pick the chart for the question**: trend over time → line; comparison across
  categories → bar; distribution → histogram/box; relationship → scatter. A pie
  chart is almost never the answer.
- **Show the sample size.** `n` in the caption, or the raw points under the
  summary.
- **One message per chart.** If it takes a paragraph to explain, it is two charts.
- **No dual y-axes to imply a link** that the data does not support.

The test: could a careful reader be *misled* by this chart into believing
something the data does not show? If yes, fix the chart, not the caption.
