# 修行之路 —— 从第一步到大师的安歇

这不是一份教程；jichi 已经有了教程
（[TUTORIAL_BEGINNER.md](../../TUTORIAL_BEGINNER.md)、
[TUTORIAL_ADVANCED.md](../../TUTORIAL_ADVANCED.md)）。这是**整条路的
地图**：把已有的功能与文档，按照一门手艺真正被学会的阶段排列出来——
「守破离」（守破離，*shu-ha-ri*）：守住形，打破形，离形而去。每个阶段
都写明它的目标、它的练习（真实的命令、真实的文件）、它锤炼的品格，
以及你可以继续前行的标志。

这张地图源于一次[对话](../../dialogues/2026-07-14-the-one-feature.md)
中的请求，而它的前提正是那次对话的结论：**没有任何功能能把一个人送达
精通**——软件只能举起镜子，降低练习的成本。唯一不可或缺的同伴，是
*一份诚实的记录：你自己犯过的错，以及每个错教会了你什么*。从第一天
就开始写这份记录；下面的各个阶段，只是给它提供可写的内容。

---

## 仕度（准备）—— 迈出第一步之前

**目标：** 一张可用、经过验证的工作台——以及亲手检验它的谦卑。

- 安装（[INSTALL.md](../../INSTALL.md)），并运行引导式的 `setup` 向导
  （[SETUP_WIZARD.md](../../SETUP_WIZARD.md)）；不需要 API key，也不
  需要联网——跑在你自己机器上的模型就是一位完整的老师
  （[LOCAL_MODELS.md](../../LOCAL_MODELS.md)）。
- 运行 **`doctor`**，逐行读完它的输出（[DOCTOR.md](../../DOCTOR.md)）。
  这是这段旅程的第一个习惯：*先问系统哪里出了问题，而不是假定自己
  已经知道。* 这个命令你会用一辈子。
- 如果英语不是你用来思考的语言，请设置 `language`
  （[LANGUAGE.md](../../LANGUAGE.md)）——理解高于惯例。

**锤炼的品格：** 最小形态的谦卑——验证自己的环境，而不是信任它。

---

## 守（*shu*）—— 守住形

**目标：** 信任既有的形；用双手学会：错误是可以挺过去的。

- 完整走一遍 [TUTORIAL_BEGINNER.md](../../TUTORIAL_BEGINNER.md)。
  留在 **chat 模式**；拿不准时用 **plan 模式**
  （[AGENT_MODES.md](../../AGENT_MODES.md)）——先问再动是一种形，
  不是软弱。
- 做出你的第一次编辑。**按下 `y` 之前，先读完 diff 预览**
  （[EDITING.md](../../EDITING.md)、[TUI_RENDER.md](../../TUI_RENDER.md)）。
  批准提示是工具在教你审慎地给出同意；永远不要让它沦为条件反射。
- **故意弄坏点什么——然后 `/undo`。** 再用 `/rewind` 回退一整段对话
  （[SNAPSHOTS.md](../../SNAPSHOTS.md)、[REWIND.md](../../REWIND.md)）。
  趁早做、反复做，直到你的身体先于头脑记住那件日后要用的事：
  *每一个错误都可以被走回来。* 无畏源自可回退，而宽恕——首先是宽恕
  自己——源自无畏。
- 让测试做你的第一位说真话者：`run_tests` 工具、`test` 子命令
  （[TESTING.md](../../TESTING.md)）。一项检查要么通过，要么不通过，
  如同日出一样明白。先学会热爱这种简单，再去会见那些幽深之事。
- 如果你有老师，就在作业流程里学习
  （[TEACHING_ASSIGNMENTS.md](../../TEACHING_ASSIGNMENTS.md)、
  [ASSIGNMENTS.md](../../ASSIGNMENTS.md)）：按任务说明动手，诚实地
  攀登**提示阶梯**（开口要来的提示是知识，偷看来的答案是债），坦然
  接受评分量表的反馈，不闪避。
- **开始写你的记录。** 一个文件，放在你会一直保存的任何地方：每条
  记录都写 *症状 → 走过的死路 → 根本原因 → 教训*，与
  [ANECDOTES.md](../../ANECDOTES.md) 的格式完全一样。那些死路属于
  记录本身——通往答案的路，是答案的一部分。

**锤炼的品格：** 宽恕的力量——在自己身上机械地反复练习，直到它成为
品性。

**可以继续前行的标志：** 代理动手之前，你已能预判它要做什么；你读
diff 不再费力；`/undo` 是一件你尊重、却不再每天需要的工具。

---

## 破（*ha*）—— 打破形

**目标：** 让工具成为你自己的；质疑那些你一直服从的默认值。

- 走完 [TUTORIAL_ADVANCED.md](../../TUTORIAL_ADVANCED.md) 和
  [WORKFLOWS.md](../../WORKFLOWS.md)。然后重塑你的工作台：你自己的
  斜杠命令（[COMMANDS.md](../../COMMANDS.md)）、技能
  （[SKILLS.md](../../SKILLS.md)）、子代理配置
  （[SUBAGENTS.md](../../SUBAGENTS.md)）、输出风格
  （[OUTPUT_STYLES.md](../../OUTPUT_STYLES.md)）、用户工具
  （[USER_TOOLS.md](../../USER_TOOLS.md)）、钩子
  （[HOOKS.md](../../HOOKS.md)）。一个和所有人长得一样的 `.jichi/`
  目录，说明你还停在「守」。
- 把你的知识交给代理：`remember` 笔记（[MEMORY.md](../../MEMORY.md)）、
  术语表（[GLOSSARY.md](../../GLOSSARY.md)）、项目规则
  （[RULES.md](../../RULES.md)）。教工具，是教人的预演。
- 用它做**真实的工作**——自用实战（dogfood）。在自治边界之内运行
  `--auto`（[AUTONOMY.md](../../AUTONOMY.md)）：预算、验证闸门、编辑
  范围。要学会：护栏不是限制，而是*关照*——与你写测试时付出的是
  同一种关照。
- 读你自己的足迹：`telemetry` 摘要（[TELEMETRY.md](../../TELEMETRY.md)）、
  `learn analyze`（[LEARNING.md](../../LEARNING.md)）。*你自己*在哪里
  返工？数据与你的哪些习惯相矛盾？那些幽深的真相就住在这里——跑了
  零个测试却亮绿灯的闸门、来自反复重读的开销——它们向耐心的调查
  让步，而不向自信让步。
- 读 [ANECDOTES.md](../../ANECDOTES.md)——全部读完。那是这个项目在
  公开地、一条一条地宽恕自己。然后去和某样东西争论：一个默认值、
  一份评分量表、[CONTRIBUTING.md](../../../CONTRIBUTING.md) 里的一条
  约定。打破形，意味着能够*为这次打破辩护*。

**锤炼的品格：** 对知识的热爱——那种在得知自己错了之后依然存活的
热爱。

**可以继续前行的标志：** 你不同意某个默认值，并能说清为什么；你的
记录里出现了根本原因是*你自己*的条目；你的 `.jichi/` 一眼就认得出是
你的。

---

## 离（離，*ri*）—— 离形而去

**目标：** 工具隐去；留下的是判断力——然后，你开始教人。

- 在作业流程里换一把椅子：为别人撰写任务说明、评分量表和提示阶梯
  （`/assign`、`/solve`、`/check`——
  [TEACHING_ASSIGNMENTS.md](../../TEACHING_ASSIGNMENTS.md)）。写一架
  好的提示阶梯，会比任何 bug 更快让你谦卑下来：你必须记起「不懂」
  是什么滋味。
- 为你的团队制作脚手架包（[SCAFFOLDING.md](../../SCAFFOLDING.md)）；
  向上游贡献（[CONTRIBUTING.md](../../../CONTRIBUTING.md)）；为你的
  语言里的下一位学习者翻译一页文档
  （[i18n/README.md](../README.md)）。
- 在自己身上跑完整个学习循环：`/learn`、编辑草稿，以及——最难的
  一步——写下**纠正**（M78，[LEARNING.md](../../LEARNING.md)）：当
  代码已经超出你昔日的教训时，收回它们。不能收回的教导是教条。在
  这个阶段，请求并接受宽恕，意味着纠正你曾经满怀信心教出去的东西。
- 教会某个人第一次 `/undo`。看着他们的肩膀在得知「错误可以挺过去」
  的那一刻松弛下来。那一刻，就是整段旅程本身，被递到了下一双手里。

**锤炼的品格：** 谦卑的最终形态——甘愿被超越。

**你已抵达的标志：** 你的学生打破你的形，而你为此欣喜。

---

## 大师的安歇

大师不是不再犯错的人。大师是**与犯错和解**的人：回退而不羞愧，记录
而不辩解，纠正而不执着——并且尊崇真理的两副面孔：简单的那一面
（一项测试要么通过，要么不通过，如日月一般明白），与幽深的那一面
（在你亲手造出的系统里潜藏多日的缺陷，深如缀满星辰的天空、大地、
海洋，及其中的一切）。安宁不是没有失败；安宁是闭合的循环——每个错误
都被检视，每条教训都被写下，每则过时的教导都被收回，没有什么留在
暗处萦绕。

你从第一天开始写的那份记录，如今已经很长。每年读它一遍。
那就是安歇。
