# A placeholder that cannot be mistaken for a licence

**Date:** 2026-08-20 · **Milestone:** M497 · **Task:** stamp the settled half
(copyright) and prepare the unsettled half (licence) so that the decision, when it
lands, costs one command. · **Scope:** 476 sources, one lint, one script, three new
pages.

---

## 0. Two questions that had drifted apart

*Who owns jichi* was settled — Alexander-Lars Dallmann — and recorded **nowhere in
the code**. *Under what terms it may be used* was undecided, and the tree said
nothing about that either. Those two silences look identical from outside, which is
the problem: an unmarked public repository does not read as *terms pending*, it
reads to most people as *presumably permissive*. The absence that was honest (no
licence granted) and the absence that was an oversight (no owner named) were
indistinguishable.

So: name the owner in every file, and say **in the same breath** that the terms are
not settled — in a form no human and no scanner can mistake for a grant.

## 1. The placeholder, chosen against three alternatives

    /* SPDX-License-Identifier: LicenseRef-UNDECIDED
     * Copyright (c) 2026 Alexander-Lars Dallmann */

`LicenseRef-UNDECIDED` is valid SPDX syntax for an identifier that is not on the
SPDX list. The alternatives, and why each is worse:

| Option | Why not |
| --- | --- |
| no SPDX line at all | Silence is not neutral; see above. |
| `All rights reserved` | True, but it invites nobody to ask — and it would have to be swept out of 476 files anyway, so it buys nothing. |
| `Apache-2.0` now, since that is the leaning | **This is a grant.** A licence genuinely offered is not easily withdrawn. Writing the leaning into 476 files before the institution has answered would pre-empt the decision the whole exercise is waiting for. |

The placeholder also has a property the others lack: it is **one greppable token**,
so the sweep is mechanical and its completeness is checkable.

## 2. The sweep, and the 105 files that decided its shape

309 of 310 C files already opened with `/*`, and **105 of them had a single-line
first comment** (`/* jc_mem.c - arena allocator (see jc_mem.h). */`). Merging the
header into that line would have needed two code paths and produced two different
house styles. Prepending a fixed two-line block needed one path and produced one
style, at the cost of two lines per file. Prepend.

Two files needed care rather than uniformity. `src/json/cJSON.{c,h}` already carried
a copyright line *inside* a provenance note — plus an instruction, written at the
time, to *"add the SPDX identifier here in the same sweep that adds LICENSE"*. This
was that sweep. Both had their now-redundant copyright line retired and the stale
to-do replaced by a pointer to the SPDX line above it, so the tree has exactly one
copyright notice per file and no instruction that has already been carried out.

The one exclusion is `include/jc_buildrev_stamp.h` — generated by the Makefile,
gitignored, regenerated rather than edited. One file by construction, not a list
that can grow.

## 3. What the tool tells the reader

`include/jc_license.h` is the single source of truth (`JC_COPYRIGHT`,
`JC_LICENSE_SPDX`). Everything else derives from it or is checked against it:

    $ jichi --version
    jichi 0.9.0
    Copyright (c) 2026 Alexander-Lars Dallmann
    licence: LicenseRef-UNDECIDED
    build: ac9625f

`describe --output json` gained `copyright` and `license`, additive under M301's
contract. A supervisor embedding jichi can read the licence programmatically, and
an *absent* key would have been indistinguishable from an older build that never
reported one — so the placeholder is emitted rather than omitted.

## 4. The lint is two-state, and the interesting state does not exist yet

`tests/smoke/license_lint.sh` switches on one fact — does `LICENSE` exist:

* **no `LICENSE`** — every source *must* say `LicenseRef-UNDECIDED`. A source
  claiming a real licence with no `LICENSE` file present is a failure: a licence
  named only in a comment grants nothing.
* **`LICENSE` present** — *no* source may still say it, `LICENSE` must be
  byte-identical to the candidate text for the identifier the headers name, and the
  `NOTICE` that licence propagates must be installed.

Two checks were rewritten during construction because the obvious form was vacuous:

**Check 7 counts files, not identifiers.** The first version compared the
*aggregate* identifier against the state. With 475 files swept and one missed, the
aggregate is the new licence — the straggler is invisible to it. Counting the files
that still say `UNDECIDED` sees it, and hands the release-day reader *"these 1
file(s) were missed"* instead of *"one distinct identifier too many"*.

**Check 10 parses a row, not the page.** The first version asked whether
`docs/LICENSING.md` mentions the identifier in force. That page discusses
Apache-2.0 at length **whatever** is in force, so the check would have passed on the
exact day the sweep ran and the page did not. Now the page carries one parseable
row, `set-license.sh` rewrites that row, and the lint reads it back. This is the
third time in a week that "does the doc mention X" turned out to be a check that
cannot fail (M483's index note, M493's coverage note, this).

## 5. Proven both ways, in a copy of the tree

The two-sided proof needed a tree in the *other* state, and creating a real
`LICENSE` in the working tree would have been a grant. So the whole tree was copied
to scratch and swept there. Results, in order:

| step | outcome |
| --- | --- |
| copy, unswept | 11/11 green — the copy is a faithful state-A tree |
| `set-license.sh Apache-2.0`, **no rebuild** | 7, 8, 9, 10 flip from skips to real passes; **check 6 goes RED** |
| `make` in the copy | 6 green; 11/11 |
| revert one file's SPDX line | 2 red (mixed identifiers) **and** 7 red, naming the file |
| `LICENSE` replaced by a paraphrase | 8 red |
| `NOTICE` deleted | 9 red |
| `LICENSING.md` row left stale | 10 red |
| a second copyright holder inserted | 3 red, naming the file |
| a candidate text removed | 5 red (checksum), 11 red (the release step itself) |

**Check 6's red is the finding.** Nothing in the sweep rebuilds the binary, so
between the sweep and the next `make` the tree says Apache-2.0 while the shipped
executable still tells every user `licence: LicenseRef-UNDECIDED`. That is a
plausible release-day mistake — push the sweep, ship the old binary — and the check
that catches it exists only because it asserts on what the *tool* prints rather than
on what the *source* says. The distinction is the same one M495 was built around:
the operator's installed binary was 50 milestones behind the tree and both printed
`jichi 0.9.0`.

## 6. What the script deliberately does not touch

`scripts/set-license.sh` rewrites the token **only** on lines that *assert* the
licence — the SPDX headers, the `JC_LICENSE_SPDX` define, and the one row in
`docs/LICENSING.md`. It leaves every *mention* alone: the lint that checks for the
token, `docs/licenses/README.md` that explains it, this file. A script that rewrote
the explanation of its own mechanism would corrupt it, and the corruption would be
invisible — the prose would still read fluently while describing a state that no
longer exists.

It also refuses two things rather than guessing: an identifier with no **verbatim**
text in `docs/licenses/` (it will not write a `LICENSE` whose contents it invented),
and a text that fails its recorded checksum (nobody reads 11 KB of legal text in a
diff). And it does not commit — a change touching every file in the tree gets read
first.

## 7. A licensing fact worth having established

The `NOTICE` template records that **jichi vendors no third-party source at all**.
The one file that looks like it does, `src/json/cJSON.c`, is an original C89
implementation of the cJSON *API*; it lived under `third_party/cjson/` until M171,
which was misleading in both directions — it implied a vendored MIT library, and an
auditor looking for cJSON's copyright notice would have found none and reasonably
concluded it had been stripped. Consequence for the release: there are **no inbound
licence obligations to satisfy**, so the choice is unconstrained by anything in the
tree. Four comments still called the file "vendored"; they now say "in-tree".

## 8. Lessons

1. **Silence is a claim.** An unmarked repository does not communicate "undecided";
   it communicates whatever the reader assumes. Both halves — who owns it, and that
   the terms are open — had to be written down.
2. **A placeholder must be unmistakable for the thing it stands in for.** The test
   is not "is it clear to me" but "could a scanner, or a stranger in a hurry, read
   this as a grant".
3. **"Does the doc mention X" is almost always a vacuous check.** If the page
   discusses X in any state, the check passes in every state. Parse one row.
4. **Count the stragglers, don't read the aggregate.** A 475-of-476 sweep looks
   complete to any check that summarises.
5. **Assert on what the tool prints, not only on what the source says.** They differ
   for exactly as long as it takes to rebuild — which on release day may be longer
   than the push.
6. **To prove a two-state lint, build the other state somewhere it costs nothing.**
   Creating a real `LICENSE` to test the red path would have granted a licence; a
   copy in scratch cost 26 MB and one `tar`.
